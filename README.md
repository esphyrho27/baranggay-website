# My Barangay Website — Barangay Puntod

Responsive five-page community website built with HTML5, CSS3, and vanilla JavaScript. Open `index.html` in a browser; internet access is needed for placeholder Unsplash images and Google Maps.

## Pages

- `index.html` — Home
- `about.html` — About the barangay
- `officials.html` — Barangay officials
- `services.html` — Services, contact, map, and FAQ
- `gallery.html` — Community gallery

The shared design is in `css/style.css`, the reusable header and footer are in `js/shared.js`, and interactions are in `js/script.js`. The `images` folder contains the supplied original seal and the design reference.

Before publishing, replace placeholder officials, population, contact details, requirements, announcements, and photos with verified Barangay Hall information. The contact form is front-end only.
